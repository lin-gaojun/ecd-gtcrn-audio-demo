# ECD-GTCRN audio comparison

Six selected examples from random-room tests and fixed +x / +y noise scans.
Each example contains Clean, Noisy, SC-GTCRN, DC-GTCRN, original D-SKD,
low-weight D-SKD and ECD-GTCRN audio with synchronized spectrogram selections.

The displayed examples are selected for ECD improvements. PESQ-WB and ESTOI
refer to each complete 10-second signal. Audio amplitudes are unchanged, and
all spectrograms within an example share the same Clean-referenced color scale.
