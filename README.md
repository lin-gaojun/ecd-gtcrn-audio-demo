# ECD-GTCRN · Audio & Spectrogram Comparison

[Open the audio demo](https://lin-gaojun.github.io/ecd-gtcrn-audio-demo/)

8 samples across three scenarios: 4 random-room samples, 2 fixed +x noise samples and 2 fixed +y noise samples.
The random-room examples include two small-separation cases below 15°.
Each sample includes Clean, Noisy, SC-GTCRN, DC-GTCRN, Original D-SKD (β = 1.0), D-SKD (β = 0.25) and ECD-GTCRN.

- A/B playback of the same excerpt, with Noisy → DC → ECD, looping, reversed order and optional level matching.
- Large spectrograms with synchronized drag-to-zoom across all seven tracks.
- Full audio playback and original WAV downloads.
- One-click Chinese / English switching, with your language preference saved.

16 kHz · 10 s · SNR +5 dB · Source distance 1 m. PESQ-WB and ESTOI cover the full 10-second recordings.
All tracks within a sample share the same spectrogram color scale. Level matching applies only to A/B playback; the individual players, WAV downloads and scores use the original audio.
