# ECD-GTCRN · 音频与语谱对比

[打开在线试听页面](https://lin-gaojun.github.io/ecd-gtcrn-audio-demo/)

随机房间、固定 +x 噪声与固定 +y 噪声三类场景，共 6 组音频。
每组包含 Clean、Noisy、SC-GTCRN、DC-GTCRN、原始 D-SKD、低权重 D-SKD 与 ECD-GTCRN。

- 同一句 A/B 轮播，支持 Noisy → DC → ECD、循环、交换顺序与可选电平匹配。
- 大幅语谱图，拖拽框选后七路同步放大。
- 完整音频试听及原始 WAV 下载。

16 kHz · 10 s · SNR +5 dB · 源距 1 m。PESQ-WB 与 ESTOI 对应完整 10 秒音频。
同组语谱采用统一色标。电平匹配仅影响 A/B 试听，原始播放器、音频下载和指标保持原样。
